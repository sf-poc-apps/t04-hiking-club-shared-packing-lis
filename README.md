# Hiking Club Shared Packing List

Generated by the Software Factory POC from the `nextjs-crud` template.

A single shared packing list for one hiking club trip. Members type a first name (no login),
add items with a category and quantity, mark items packed/unpacked, filter by category, and
delete items. The list is shared and reload-safe.

## Use it

```bash
npm ci && mkdir -p public && cp sf-banner.js public/sf-banner.js
npm run build
npm start   # serves on $PORT (default 8080)
```

- Open `/` to see the list, add items, toggle packed status, filter by category, or delete items.
- `GET /healthz` returns `ok` for health checks.

## Tests

```bash
npm test       # vitest: validation, filtering, data layer, server actions
npm run build  # production build must pass
```
